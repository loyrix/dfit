## Notes on reading this

- **Two accounts dominate.** `jethavadarshan` and `aideveloperemp` account for 49
  of 75 sessions (65%) and 84 of 129 turns. Excluding them plus `jsatyam4` and
  `rameshtest`, genuine external usage is 14 users across 21 sessions.
- **"Closed" is almost always empty.** Only 3 sessions ever show a close time —
  the ones that hit the 15-turn cap. `closeChatSession` also fires on
  `[END_SESSION]`, but the active `nutritionist_prompt` in the database contains
  no `[END_SESSION]` instruction, so that path never triggers. Everything else
  simply expires from memory after the 30-minute TTL.
- **The last three sessions (20 Aug) are the empty-reply bug**, fixed in commit
  `e6e6711`. All three turns returned the fallback message.
- **44% of sessions never get a message.** Each of those still spent a full model
  call generating a personalised greeting. See `docs/ai-integration-audit.md`, T1.
